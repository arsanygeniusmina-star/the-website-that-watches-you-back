# 👁️ The Website That Watches You Back

An experimental Next.js MVP that turns interaction behavior inside the experience into a procedural digital specimen.

## Current build

- Mysterious intro
- Four interaction experiments
- Local-only behavior aggregation
- Behavioral scoring
- Dramatic reveal
- Procedural specimen visualization
- Anonymous specimen ID
- Session reset / repeat experiment
- Responsive layout
- Reduced-motion support
- No camera, microphone, location, or private-data permissions

## Run

```bash
npm install
npm run dev
```

Then open the local URL shown by Next.js.
